# Greenlight

Self-hosted HTTP gateway that gives AI agents a **human-in-the-loop** line to
Telegram, Slack, Microsoft Teams, Discord, Google Chat, WhatsApp, and Messenger.

Agents send interactive prompts (buttons or free text). Humans answer in chat.
Greenlight delivers signed callbacks back to your agent.

Built with [Chat SDK](https://chat-sdk.dev/). Platform credentials are registered
**per channel via API** — not as global environment variables.

## What Greenlight does

1. You register a **channel** (platform + credentials + target chat).
2. Your agent creates a **prompt** or listens for inbound **messages**.
3. Humans interact in the chat app they already use.
4. Greenlight posts answers or messages to your `callback_url`.
