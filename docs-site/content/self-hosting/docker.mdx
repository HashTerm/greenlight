# Docker

Deploy Greenlight with Compose or Swarm using published GHCR images.

## Compose files

| File                                 | Role                                                  |
| ------------------------------------ | ----------------------------------------------------- |
| `docker-compose.self-host.yml`       | API + UI + Postgres (GHCR images)                     |
| `docker-compose.self-host.stack.yml` | Swarm — standalone stack (API + UI + docs + Postgres) |
| `docker-compose.docs.yml`            | Docs overlay on self-host (GHCR image)                |
| `docker-compose.docs.build.yml`      | Standalone docs — build on server                     |

## Docs site

**Alongside gateway** (pull GHCR docs image):

```bash
docker compose -f docker-compose.self-host.yml -f docker-compose.docs.yml \
  --env-file .env.self-host --env-file .env.docs up -d
```

Ingress → `greenlight-docs:3003`.

**Docs only** (build on server — Dokploy compose file `docker-compose.docs.build.yml`):

```bash
docker compose -f docker-compose.docs.build.yml --env-file .env.docs up -d --build
```

Set `NEXT_PUBLIC_DOCS_URL` in `.env.docs` (see `.env.docs.example`).

## Environment

Generate secrets (when `.env.self-host` is missing):

```bash
npm run env:ensure -- --profile self-host
```

Or copy [`.env.self-host.example`](https://github.com/markokosticdev/greenlight/blob/main/.env.self-host.example)
and set secrets yourself.

## Single node

```bash
docker compose -f docker-compose.self-host.yml --env-file .env.self-host up -d
```

## Swarm

```bash
docker stack deploy \
  -c docker-compose.self-host.stack.yml \
  greenlight
```

API and Admin UI use `start-first` rolling updates with healthchecks so the new
task is healthy before the old one stops. Postgres uses `stop-first` (single
volume) and briefly restarts on image updates.

## Migrations

On container start:

- **core** applies `schema.sql` (`prompts`, `channels`, …)
- **ui** applies Drizzle SQL via its Docker entrypoint (`admin_users`)

## Route traffic

| Service        | Target               | Role      |
| -------------- | -------------------- | --------- |
| API + webhooks | `greenlight:8100`    | Gateway   |
| Admin UI       | `greenlight-ui:3000` | Admin app |
