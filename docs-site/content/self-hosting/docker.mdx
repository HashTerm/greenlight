# Docker

Greenlight ships with Compose files for development, self-hosting,
optional docs, and Swarm.

## Development

```bash
cp .env.example .env
# Set API_KEY, ADMIN_INTERNAL_TOKEN, AUTH_SECRET, CALLBACK_SIGNING_SECRET, WEBHOOK_SECRET

docker compose up -d --build
# same as: docker compose -f docker-compose.dev.yml up -d --build
```

Services:

| Service | Host port | Role |
|---------|-----------|------|
| `greenlight` | 8100 | API + webhooks |
| `greenlight-ui` | 3000 | Admin UI |
| `greenlight-docs` | 3001 | Product docs |
| `postgres` | 5432 | PostgreSQL 16 |

Useful commands:

```bash
docker compose -f docker-compose.dev.yml ps
docker compose -f docker-compose.dev.yml logs -f greenlight greenlight-ui greenlight-docs
curl http://localhost:8100/healthz
```

## Hybrid local development

Run Postgres (and optionally core) in Docker; run apps with npm:

```bash
npm install
cp .env.example .env
# DATABASE_URL=postgresql://greenlight:greenlight@localhost:5432/greenlight

docker compose -f docker-compose.dev.yml up -d postgres
npm run dev:core    # API on :8100
npm run dev:ui      # Admin UI on :3000
npm run dev:docs    # Docs on :3001
```

## Migrations

| Component | Mechanism | When |
|-----------|-----------|------|
| **core** | `schema.sql` applied on boot | Every start (`prompts`, `channels`, …) |
| **ui** | Drizzle SQL via Docker entrypoint | Container start (`admin_users`) |
| **ui (manual)** | `cd ui && npm run db:migrate` | Local hybrid setups |

## Self-host Compose

| File | Role |
|------|------|
| `docker-compose.yml` | Default entry — includes `docker-compose.dev.yml` |
| `docker-compose.dev.yml` | Local development — build all services + host ports |
| `docker-compose.self-host.yml` | Self-host — API + UI + Postgres (GHCR images) |
| `docker-compose.docs.yml` | Optional overlay — adds product docs |
| `docker-compose.self-host.stack.yml` | Swarm overlay — deploy policies + overlay network |

Env examples:

- [`.env.self-host.example`](https://github.com/markokosticdev/greenlight/blob/main/.env.self-host.example) — product
- [`.env.docs.example`](https://github.com/markokosticdev/greenlight/blob/main/.env.docs.example) — docs overlay

Product only (Dokploy / single node):

```bash
cp .env.self-host.example .env.self-host
# Edit secrets, then:
docker compose -f docker-compose.self-host.yml --env-file .env.self-host up -d
```

Product + docs:

```bash
cp .env.docs.example .env.docs
docker compose -f docker-compose.self-host.yml -f docker-compose.docs.yml \
  --env-file .env.self-host --env-file .env.docs up -d
```

Swarm (product + docs):

```bash
docker stack deploy \
  -c docker-compose.self-host.yml \
  -c docker-compose.docs.yml \
  -c docker-compose.self-host.stack.yml \
  greenlight
```

Route traffic:

| Service | Target | Role |
|---------|--------|------|
| API + webhooks | `greenlight:8100` | Gateway |
| Admin UI | `greenlight-ui:3000` | Admin app |
| Docs (optional) | `greenlight-docs:3001` | Product docs |
