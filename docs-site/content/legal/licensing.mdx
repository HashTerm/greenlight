## Change Date

Under BUSL-1.1, each version eventually converts to Apache License 2.0. For this
distribution the Change Date is four years from first public publication, and no
earlier than **2030-07-25**. See repository `NOTICE`.

Enterprise proprietary code does not automatically become Apache-2.0.
