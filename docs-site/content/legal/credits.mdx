# Credits

Greenlight builds on open-source projects. These are the main ones that power
the gateway, admin UI, and platform adapters — not a full dependency inventory.

| Project                                                         | Role                                              |
| --------------------------------------------------------------- | ------------------------------------------------- |
| [Chat SDK](https://chat-sdk.dev/)                               | Chat platform adapters and bot runtime            |
| [Hono](https://hono.dev/)                                       | Core HTTP API                                     |
| [Zod](https://zod.dev/)                                         | Request and config validation                     |
| [PostgreSQL](https://www.postgresql.org/) / [node-postgres](https://node-postgres.com/) | Persistence for channels and prompts |
| [Next.js](https://nextjs.org/)                                  | Admin UI                                          |
| [Auth.js](https://authjs.dev/) (NextAuth)                       | Admin UI sessions                                 |
| [Drizzle ORM](https://orm.drizzle.team/)                        | Admin UI database migrations                      |
| [Nextra](https://nextra.site/)                                  | Product documentation site                        |

Each project remains under its own license. See the repository `LICENSE` and
[Licensing](/legal/licensing) for Greenlight’s terms.
